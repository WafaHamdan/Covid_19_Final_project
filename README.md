# COVID-19 Prediction Model

A machine learning project developed to predict COVID-19 cases based on symptoms and related health indicators.

## Project Overview

The project involved preparing and analyzing the dataset, identifying important patterns, and comparing multiple classification models to determine the best-performing model.

## Project Workflow

- Cleaned, validated, and prepared the dataset for analysis.
- Performed exploratory data analysis (EDA).
- Encoded categorical variables and standardized the data.
- Applied feature engineering techniques.
- Used SMOTE to address class imbalance.
- Trained and evaluated Logistic Regression, K-Nearest Neighbors (KNN), and Decision Tree models.
- Used accuracy and 10-fold cross-validation to compare model performance.

## Results

The Decision Tree model achieved the strongest performance:

- Holdout test accuracy: **96.86%**
- Mean 10-fold cross-validation accuracy: **96.74%**
